Number Analyzer

A simple web application that analyzes a number and displays its mathematical properties.

Features

- Even / Odd
- Prime Number
- Reverse
- Palindrome
- Sum of Digits
- Largest & Smallest Digit
- Number of Digits
- Armstrong Number
- Factors

Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

How to Run

1. Clone the repository.
2. Install the required Python packages.
3. Run the Flask application.
4. Open the application in your browser.
