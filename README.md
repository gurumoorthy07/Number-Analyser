Number Analyzer

A simple web application that analyzes a number and displays its mathematical properties.

Features

Even / Odd
Prime Number
Reverse
Palindrome
Sum of Digits
Largest & Smallest Digit
Number of Digits
Armstrong Number
Factors
Technologies Used

Python
Flask
HTML
CSS
JavaScript
JSON/REST API
How to Run

Clone the repository.
Install the required Python packages.
Run the Flask application.
Open the application in your browser.
